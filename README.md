# 汉诺塔 · Tower of Hanoi

一个单文件的汉诺塔小游戏：`hannuo.html`。CSS 和 JS 全部内联，没有构建步骤、没有依赖 —— 用浏览器直接打开就能玩。

## 玩法

- **5 个圆盘**，一开始全部叠在第 ① 根柱子上，目标是把它们全部搬到第 ③ 根。
- **按住最上面的圆盘，拖到另一根柱子上**松手即可。
  （注意：不支持"点一下拿起、再点一下放下"，单击只会给出提示。）
- 每个圆盘尺寸都不相同，**大圆盘不能压在小圆盘上**；这样的操作算一次失误。
- **失误满 3 次本局结束**。计时从第一次合法移动开始。
- 把 5 个圆盘全部搬到第 ③ 根即过关，最少需要 **31 步**。

## 放弃 · 看解法

不会玩的时候，点工具栏的 **「放弃 · 看解法」**：

- 会先把盘面**重置到开局**，然后自动演示一遍 **31 步的最少步数解法**（每步 0.45 秒）；
- 演示期间可以随时点 **「停止演示」** 打断；演完停在解开的盘面，按钮变成「再看一遍」；
- 演示**不计时、不计失误、不会写入纪录**，所以可以放心看。

## 纪录与音效

- 最好成绩保存在浏览器的 `localStorage`（键名 `hanoi-best`），按"步数优先、时间次之"更新。
  换浏览器或清除站点数据就会丢失。
- 音效由 WebAudio 实时合成；工具栏的 🔊 按钮可以开关。

## 运行

直接双击 `hannuo.html` 用浏览器打开即可，不需要安装任何东西、也不需要本地服务器。

## 开发说明

游戏逻辑里的几条关键规则（改动时请务必保留）：

- 圆盘编号 `0..N-1`，**编号 0 是最大的盘**，初始时在最底下；柱子数组是"从底到顶"，所以栈顶是数组的**最后一个**元素。
- 判定合法性：`topOf(from) > topOf(to)` —— 编号越大代表盘越小。
  因此编号 2 比编号 4 **更大**，"把 2 号盘放到 4 号盘上"会被正确拒绝。
- 布局用百分比，随 `#board` 缩放：`pegX=[16,50,84]` 是柱子中心的百分比，
  `BASE=15.5556` / `STEP=6.6667` 是圆盘底部偏移量；它们与 CSS 里 `.rod` 的
  `bottom` / `height` 必须**同步修改**。
